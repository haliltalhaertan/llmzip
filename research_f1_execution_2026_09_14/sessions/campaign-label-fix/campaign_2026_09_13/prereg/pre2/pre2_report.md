## (b) Do NOT add (scope creep to resist)

1. **Learned-selection arm (any variant: drop/alone/delta, per-type, transferred).** Killed by pre-declared gate (3/3 triggers; null pct 57/89th = no-premium zone; Jaccard 0.329 unstable). Re-adding = post-hoc gate override. Cite as disclosed kill only.
2. **Hetero-precision / mixed-bitwidth codecs (ideas A1: S48+8×2 etc.).** Respects the facts but touches two NOES items (alternate widths as claims + learned/threshold learning) and needs its own preregistration with frozen m, threshold-source, distance rule. Note as future work with pilot path (train-only thresholds → disclose → preregister); not one more arm in this race.
3. **Adaptive routing / per-question masks (c2/A5).** CLOSED same-day: m3 formal vs-random puts LME α=0.20 in noise (p_bonf 0.18), LoCoMo empty at all α; m2 gold-free G 0/10 splits ≥0.65 (mean 0.555). Salvage = descriptive sentence only (LME COMBO AUC 0.686 vs LoCoMo 0.558 ≈ chance; LARGE-free ablation AUC 0.670/0.568, gains inside noise at α=0.20). No routing arm, no abstention analysis in the race.
4. **PCA / whitening / learned rotations / supervised rotation / variance reweighting at decode / float rerank / alternate metrics.** All NOES-gated, all ex-ante negative (rotations proven bad; reweighting breaks byte comparability; rerank defeats the budget). Ideas-doc rejections #2–#4 stand.
5. **Dither / deadzone / companding / ternary codecs (A3/A4).** Mechanism-targeted but each needs dose-response piloting + threshold-NOES disclosure + determinism risk (bit-reproducibility is a programme asset). Note B5 curves (|q|/margin conditioning) as the cheap killer/licenser, not as arms.
6. **New-encoder generality (e2).** Ill-posed until mechanism narrows (SVD fork unsettled); needs new adapter + leakage audit + anchors + pins. At most a scoping-decision note.
7. **Cross-benchmark utility transfer as a race arm.** e1 verdict: Spearman ~0.1, transfer ≈ chance (C5); utilities benchmark-local. Transfer matrix stays a disclosed pilot, not an arm.
8. **Global/cross-archive codebooks.** Draft freezes archive-local fitting; global codebooks are a different deployment config — out of scope, not a "fairer PQ" variant.
9. **Sub-8-bit direction, per-type selection rules, PR-weighted codecs.** One k=16/24 confirmatory point (C4) and descriptive per-type tables (C6) only.
10. **Trial-count or estimator changes mid-race.** 20 tie trials + fractional R@3 + top-3 stay frozen; 100-trial tie-mass work is a descriptive sensitivity, not a replacement estimator. No vs-mean headlines (R2D F3/F12 lesson).

## (c) Evaluation-semantics recommendation (draft's biggest hole)

**Recommended frozen choices (write verbatim into the preregistration):**

1. **Task wrapper identical for every arm (the fairness core).** Same C/Q matrices (centered, frozen), same archives/questions, same K=3, same estimator, same 20 tie-priority draws (`rng(5_100_000+lex*100_000+t*100+99)` / LoCoMo `stable_archive_seed(ci,t)+99`), same per-question-then-aggregate order. The estimand is *retrieval outcome under an identical task*, never a distance-scale comparison — that is the fairness argument for comparing FR across Hamming, asymmetric (RaBitQ), and ADC (PQ) scores.
2. **Estimator: per-question fractional R@3, then mean.** For question q with gold set G: score every doc, rank top-3 under tie-priority draw t, credit = |retrieved ∩ G|/min(3,|G|) with exact-tie mass split fractionally (frozen rule); arm score = mean over 20 draws, then mean over questions. Report per-question arrays for every arm/seed (draft already requires persistence) so W/T/L (C6) and bootstraps (C8) are recomputable.
3. **Ties.** Sign/Hamming arms: ties are load-bearing (R2A 250/470; D2 mechanism) — 20 draws stand. Continuous-score arms (RaBitQ-ADC-style, PQ-ADC): exact float ties are measure-zero; run the SAME 20 draws anyway (protocol identity) with exact-equality tolerance 1e-12; draws will almost always agree — report trial-SD (expect ≈0) rather than skipping. No jitter, no dither, no re-ranking. Deterministic lexsort ordering under each draw.
4. **Distance rule per family (frozen, no per-question tuning).** Sign subsets: Hamming on the selected bits. RaBitQ32 plain = PRIMARY: codec-native asymmetric distance with the pinned faiss chain exactly as installed (verify rotation chain empirically; record which rotation, if any, the wrapper applies). RaBitQ32+random-rotation wrapper = SECONDARY (sensitivity, both namings carried per draft). PQ m=12×8bit: ADC (asymmetric distance computation) against the archive-local codebook; no residual rerank, no float shortlist. Norm/scale/correction scalars count toward the 12B cap and, if within cap, are used at decode exactly as stored (no recomputation from full vectors at query time).
5. **Centering.** All arms use the frozen centered pipeline (`D=(C>=0)`, `Q=(qC>=0)` for sign arms). Non-sign arms encode the SAME centered vectors (or document the deviation as a protocol violation). Rationale: centered SIGN96's +10pp over float may be a centering/hubness artifact (roadmap §2.2) — letting one family silently change centering confounds the codec contrast. Median-shift (C7) is the declared instrument for testing threshold sensitivity, not an undocumented per-arm choice.
6. **K.** K=3 frozen. K-sweeps are descriptive only and do not enter gates (top-3 boundary tie-mass is the proven decision variable; D2).
7. **Bytes.** Pre-compute abort `measured_bytes == declared_bytes` on serialized per-vector payload (code + all per-vector metadata). Shared state reported separately (C11). PQ per-archive effective cost reported (small archives!). A7-44B never enters pairwise gates — curve only.
8. **Comparisons are per-question paired.** Primary statistic = per-question difference SIGN−rival averaged (paired bootstrap CI), NOT difference of independently-bootstrapped means. LoCoMo adds conversation-cluster bootstrap. No pooling across benchmarks.

**Fairness sentence for the sealed text:** "All codecs solve the same retrieval task — same queries, same archives, same K, same estimator, same tie draws, same byte cap enforced on measured payload — with per-question pairing; score-scale differences are absorbed by rank-based FR@3, and byte-scale differences by the measured-bytes abort plus the recall-vs-measured-bytes dominance check."

## (d) Pre-seal checklist proposal (minimal, must all pass)

1. HR approval line signed; seal commit hash recorded; nothing runs before it.
2. Native reproduction aborts: LME 0.5419751773049645 / LoCoMo 0.23654714666441054, tol ≤1e-12, recomputed in-run first.
3. Seed literals frozen in runner: 10/width for random panels (`93000+10*width_idx+j` extended to j=0..9 or fresh literals), 20 tie draws, bootstrap B + seeds.
4. `measured_bytes == declared` abort fires on every arm (incl. RaBitQ/PQ serialization check §8.5); byte worksheet per arm (marginal vs shared vs per-archive-effective).
5. Construction asserts: `eff_k==k`, logged column lists, no sentinels (SPREAD repaired rank-linspace; BOT construction logged); tie-seed identity across arms.
6. Third-party pins: faiss-cpu exact version + wheel sha256, installed-not-vendored, import-version assert; rotation-chain empirical verification logged.
7. Negative controls: one failing example recorded per abort (wrong native value, wrong byte count, eff_k≠k, sentinel cols, mismatched tie seeds) proving each check can fail.
8. Dry run: 5-question end-to-end per benchmark reproducing gates + manifest shape before full run.
9. Artifact manifest: per-question records per arm/seed, column lists, configs, hashes (`sha256sum -c` ALL OK), no-network attestation, read-only /mnt/c respected.
10. Disclosure boilerplate travels with the sealed text (r1+r2+r3 + m1/m2/m3 + R2D/D5 errata + learned-arm kill numbers + adaptive-closure numbers), plus the C9 null/positive criteria and the C1 dual-bar + C4 curve specs.
