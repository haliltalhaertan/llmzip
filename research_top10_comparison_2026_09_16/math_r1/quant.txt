ARM FAMILY C - ITQ (Iterative Quantization, Gong & Lazebnik-style alternating minimization).
  Find an orthogonal R (96x96) minimizing the quantization loss || sign(C R) - C R ||_F^2, then code
  bits = sign(C R), and rotate the query the same way before scoring.
  Alternate to convergence: B <- sign(C R); then R <- U V^T from the SVD of C^T B. Fix iterations = 50
  and init from a random orthogonal matrix with seed 20260916, DECIDED NOW, not tuned afterwards.
  Fit R on DOCUMENTS ONLY, per archive. Never use queries or gold.
  Rationale: sign() is cheapest when the mass sits away from the axis-aligned hyperplanes; ITQ
  rotates the cloud to minimize exactly the information destroyed by thresholding at zero.

ARM FAMILY D - random rotation control (the honest control for C).
