The project asks: can you compress a document embedding down to ~12-48 BYTES and still retrieve
the right document? Encodings tested include sign codes (1 bit per projected dim), quantized

baselines. Datasets: RealTalk, PerLTQA, LoCoMo, LME. Metric: Hit@10 / FR@3 style retrieval.
A BM25 lexical baseline is the competitor. Recent conclusion was "STOP the pilot" because a
fairly-tuned BM25 (65.67 Hit@10 on RealTalk) beat the best 48-byte code (57.87).
